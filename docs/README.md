Two documents about the plugin as built. They describe; they do not specify. The specification is `spec/`, and the binding rules are in `CLAUDE.md`.

| Document | Read it for |
|---|---|
| [state.md](state.md) | What exists now: what works, what is not done or not verified, where the code is, how to run it, where the build differs from the spec as received |

Both were written on 2026-11-19, after the manual-testing round that produced decisions D33 to D38. Update them when the state changes; a stale state document is worse than none.
